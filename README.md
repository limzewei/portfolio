# Lim Ze Wei — Engineering Portfolio

Personal engineering portfolio for full-time and selected contract opportunities.

## Stack

- Next.js 16.3.3
- React 19
- TypeScript
- Plain CSS
- Vercel-ready

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build

```bash
npm run build
npm start
```

## Deploy

This repository is intended to deploy through Vercel Git integration. Import the repository in Vercel and use the default Next.js settings.
